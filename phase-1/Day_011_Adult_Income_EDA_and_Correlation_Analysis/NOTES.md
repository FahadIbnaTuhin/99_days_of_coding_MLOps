# Day-011: Adult Income Dataset

## What I Learned
- Loading CSV files without headers using `header=None`.
- Assigning column names manually using `df.columns`.
- Inspecting datasets using Pandas.
- Identifying missing values represented by `?`.
- Practising EDA on a new dataset.
- Visualizing relationships using scatterplots.
- Keeping the X-axis fixed (`age`) while changing four Y-axis columns:
  - `hours-per-week`
  - `education-num`
  - `capital-gain`
  - `capital-loss`
