# Day-012: Pima Indians Diabetes Dataset

## What I Learned
- Loading CSV files without headers using `header=None`.
- Understanding dataset documentation and column descriptions.
- Assigning meaningful column names using `df.columns`.
- Identifying zero values that may represent missing measurements.
- Practising EDA on a new dataset.
- Visualizing relationships using scatterplots.
- Keeping the X-axis fixed (`Age`) while changing four Y-axis columns:
  - `Glucose`
  - `BloodPressure`
  - `BMI`
  - `Insulin`
