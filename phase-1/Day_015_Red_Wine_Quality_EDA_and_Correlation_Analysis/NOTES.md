# Day-015: Red Wine Quality EDA

## What I Learned

- Loading CSV files using `pd.read_csv()`.
- Using `sep=';'` to read semicolon-separated CSV files.
- Exploring datasets using `head()`, `info()` and `describe()`.
- Checking missing values using `isnull().sum()`.
- Understanding relationships using scatterplots.
- Keeping the X-axis fixed (`alcohol`) while changing four Y-axis columns:
  - `quality`
  - `fixed acidity`
  - `volatile acidity`
  - `sulphates`
- Observing positive/negative relationships, clusters and outliers.

## Dataset

Red Wine Quality Dataset (Kaggle).
