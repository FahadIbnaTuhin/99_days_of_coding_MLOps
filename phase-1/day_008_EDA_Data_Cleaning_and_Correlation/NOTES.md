# Day-008: EDA (Titanic Dataset)

## What I Learned
- Loading datasets using Pandas.
- Inspecting data using `head()`, `tail()`, `info()`, and `describe()`.
- Identifying and handling missing values using `isnull()` and `fillna()`.
- Finding unique values using `unique()`.
- Visualizing data using histograms and countplots.
- Filtering data and comparing survivors vs non-survivors.
